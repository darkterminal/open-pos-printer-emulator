# Support

## Getting Help

- **Documentation:** Start with [docs/user-manual/](docs/user-manual/index.md) and the [README](README.md).
- **Troubleshooting:** See [docs/user-manual/troubleshooting.md](docs/user-manual/troubleshooting.md).
- **Bug reports:** Open a [GitHub issue](https://github.com/darkterminal/open-pos-printer-emulator/issues/new/choose) with reproduction steps, logs, and payload/sample when possible.
- **Feature requests:** Open a GitHub issue describing the problem, proposed behavior, and scope.
- **Security issues:** Follow [SECURITY.md](SECURITY.md). Do not open public issues for sensitive vulnerabilities.

## Project Scope

Open POS Printer Emulator is a **development tool** for testing ESC/POS integrations without physical printers. It is **not recommended for production deployment**.
