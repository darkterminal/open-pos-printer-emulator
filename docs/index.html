Test ESC/POS flows without a physical printer.

Open POS Printer Emulator is a self-hosted web app for testing ESC/POS integrations. Send raw bytes over TCP, inspect parsed commands, preview receipts, and debug print jobs in real time.

Development only: designed for local dev/QA, not recommended for production deployment.

Get started Read the manual

Works with any client that can send raw ESC/POS over TCP — including ESC/POS Printer Server.

bash 
curl -fsSL https://raw.githubusercontent.com/darkterminal/open-pos-printer-emulator/main/scripts/install.sh | bash

Built for real ESC/POS debugging

A practical emulator for developers and operators: capture payloads, inspect commands, and verify receipt output before touching hardware.

TCP ingest + raw payloads

Accept raw ESC/POS bytes on a TCP listener (default 9100). Raw payloads are preserved, even when parsing fails, so debugging stays possible.

Receipt preview

Visual receipt preview powered by a Node.js parser sidecar, with command inspector, warnings, and raw hex/base64 views.

Realtime jobs workspace

Live job updates via Reverb/Echo with polling fallback. Filter history, inspect details, and export/print receipts from the browser.

Listeners & profiles

Manage TCP listeners, printer profiles, and fault simulation for realistic test cases.

End-to-end with ESC/POS Printer Server

Route print jobs from ESC/POS Printer Server to OPPE over ethernet TCP. No physical printer required.

POS / Web App Creates print job
ESC/POS Printer Server WebSocket JSON
OPPE Listener TCP 9100
Jobs UI Preview & inspect

Built-in profiles are seeded from the mike42/escpos-php supported printer list. The screenshots below show real E2E captures against TM-T88V, TM-U220, ZJ-5890, and Star TSP100III profiles.

Start locally in minutes

Use Kiri (default) or Docker Compose. The Makefile supports both engines.

bash 
curl -fsSL https://raw.githubusercontent.com/darkterminal/open-pos-printer-emulator/main/scripts/install.sh | bash

The installer is for local development only. Review scripts/install.sh before running. For manual setup:

bash 
git clone https://github.com/darkterminal/open-pos-printer-emulator.git
cd open-pos-printer-emulator
cp apps/web/.env.example apps/web/.env
cp apps/sidecar/.env.example apps/sidecar/.env
make up
# Docker: make up ENGINE=docker

After startup, open http://localhost:8080 and send a test payload to localhost:9100.

Quick smoke test

  • printf "\x1B\x40Hello ESC/POS\n\x1D\x56\x00" | nc 127.0.0.1 9100
  • Open /jobs to inspect the received job

Integrate with your POS stack

  • Point your TCP ESC/POS output to the emulator listener
  • Or route ESC/POS Printer Server ethernet output to it
